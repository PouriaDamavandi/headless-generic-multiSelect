# Changelog

This changelog is summarized from the git history of this repository.

## Unreleased

### Added

- Added npm package entry point, package build config, exports map, published files list, peer dependencies, MIT license, and release guide.
- Added separate demo and package build outputs.

### Changed

- Renamed the package from `multiselectmobin-pouriadamavandi` to `react-headless-multiselect`.
- Enabled Storybook autodocs tags for the multiselect story.
- Replaced the Radix UI meta-package dependency with a native button implementation to remove Storybook's package-metadata warning.
